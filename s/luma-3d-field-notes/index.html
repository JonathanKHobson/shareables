What this shows

A fantasy game lane with real implementation teeth.

Luma 3D is still in active development, but the visible work already shows a real 3D browser-game direction rather than a static concept board. The project uses Vite, Three.js, scene systems, asset registries, collision helpers, debug shortcuts, smoke checks, and documented level-building patterns.

3D browser foundation

Three.js scenes, a GLTF main character, KayKit and voxel assets, orthographic camera work, and custom runtime systems.

Game-feel experiments

Cubeling helpers, puzzle mechanisms, river and traffic slices, dialogue flows, and Love Letter moments are being tested as small playable loops.

Local-first proof

The public repo documents commands, project structure, level registry tooling, and the current WIP caveat so reviewers can inspect the work honestly.
