How to Use the Shopify CSV

Your CSV download is a starter import file for Shopify products. It includes the recovered listing text and hosted product image links from this rescue gallery.

Quick Steps

  1. Open your Shopify admin and go to Products.
  2. Click Import, then choose the CSV file that just downloaded.
  3. Use Shopify's preview/review step to check the products before importing.
  4. After import, review each draft product before publishing it live.

Important Caveats

  • This is a draft starter CSV, not a final store setup. Prices, inventory, category, vendor, shipping, taxes, variants, and product status may need edits.
  • Products are set to draft/Published = FALSE where possible so they can be reviewed before going live.
  • Some titles and descriptions came from screenshot OCR. Proofread spelling, line breaks, and any listing marked for review.
  • Image links point to the temporary public GitHub-hosted gallery. Keep the Google Drive backup and move images into your long-term Shopify workflow when ready.
  • If you already have matching products in Shopify, be careful with overwrite options. Matching handles can update existing product records.
  • Avoid sorting or rearranging rows in a spreadsheet unless you know how Shopify product-image rows work. Extra image rows rely on staying grouped with the same product handle.

What the CSV Contains

  • One product handle per recovered listing.
  • Recovered title and description where available.
  • One image row per recovered product image, using public image URLs.
  • Suggested tags, product type, SKU, image alt text, and draft status where available.

When in doubt, import one listing first as a test, confirm it looks right, then continue with the larger CSV.
