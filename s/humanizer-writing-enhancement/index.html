Get Humanizer

01

Specificity before polish

Replace generic importance and praise with a fact, condition, action, or consequence the draft can support.

02

Voice before uniformity

Keep useful repetition, rhythm, dialect, plain verbs, and honest limits. Do not add fake roughness.

03

Evidence before assurance

Check the claim, source, location, and entailment. A citation has to support the sentence beside it.

Install it

Use the package that matches your workspace.

Each route is short. Use the live hub for the current ZIPs, then enable the skill by name when you need it.

Claude skill

Upload the ZIP

  1. Open Customize → Skills.
  2. Select Add in the upper-right, then Upload Skill.
  3. Drag in the Humanizer ZIP and enable $humanizer.
Claude skill instructions ↗

Claude plugin

Add a focused pack

  1. Open Customize → Plugins.
  2. Use the add control to upload a plugin ZIP.
  3. Invoke the included skill with / or + when needed.
Claude plugin instructions ↗

Codex

Extract the skill folder

  1. Unzip the Codex package.
  2. Place its skills/ contents in .agents/skills for a project or ~/.agents/skills for your user account.
  3. Restart or reopen Codex, then invoke $humanizer.

Copy a starting prompt

Ask for the revision you actually need.

Evidence pass
Review this draft for vague importance, unsupported benefits, and source-to-claim gaps. Keep the author’s actual voice. Return Keep, Change, and Verify.
Voice pass
Revise for clarity without sanding down my cadence. Preserve recurring terms, fragments, and punctuation unless they harm comprehension. Explain each material change.
Release gate
Run a final Humanizer pass: flag generic claims, formulaic transitions, repeated conclusions, citation issues, and anything that reads smoother than it reads true.
