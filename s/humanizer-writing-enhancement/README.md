# Humanizer GitHub Pages mirror

This folder is a static mirror of the published Humanizer Site.

- `index.html` and `assets/humanizer.css` are generated from the live rendered Site and its compiled stylesheet.
- `scripts/build-mirror.mjs` is the repeatable mirror builder.
- `downloads/` is the canonical public host for the skill archives.
- `assets/mirror.js` restores the prompt-copy buttons without needing the Sites runtime.

Refresh the mirror from the reviewed Sites build before changing its public presentation. Do not create a separate visual treatment here.
